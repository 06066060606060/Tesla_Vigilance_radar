# Tesla_Vigilance_radar

Page web de consultation de points de contrôle fixes, avec estimation des distances routières via OSRM et géolocalisation du navigateur.

Les données proviennent du [Ministère de l’Intérieur sur data.gouv.fr](https://www.data.gouv.fr/datasets/liste-des-radars-fixes-en-france/) sous Licence Ouverte 2.0. La page vérifie à l’ouverture si un CSV officiel plus récent est disponible et conserve la dernière liste valide dans le stockage local du navigateur. La copie incluse date du 30 décembre 2025 et ne couvre pas les contrôles mobiles.
